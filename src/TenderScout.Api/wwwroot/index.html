Zapytaj o dokumenty SWZ

Odpowiedź powstaje tylko z fragmentów SWZ i zawsze ma źródło. Podaj numer ogłoszenia, żeby pytać o jeden przetarg.

Odpowiedź może potrwać kilkadziesiąt sekund, najwyżej około półtorej minuty.
Każde pytanie jest osobne: asystent nie pamięta poprzednich, a rozmowa nie jest zapisywana.
